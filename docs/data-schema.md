# 数据与标签格式（待定稿）

在编写数据处理和训练脚本前，需要先确定出行链的目标结构。建议每条 JSONL 样本至少包含：

- `id`：样本唯一标识。
- `text`：原始纯文本。
- `trip_chain`：结构化出行链标注。

`trip_chain` 内建议明确以下实体或事件字段：出发地、目的地、出发时间、到达时间、交通方式、出行目的，以及多段行程的先后关系。字段是否允许缺失、时间与地点的归一化规则、跨句指代处理方式，需在开始制作训练集前统一。

数据集固定拆分为 `train.jsonl`、`validation.jsonl`、`test.jsonl`，并防止同一人物或同一原始记录跨集合泄漏。
